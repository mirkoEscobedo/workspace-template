# Ticket Tracks

Each track uses:

```text
<track>/
  master-plan.md
  track.yaml
  frontier.json
  current-sprint.md
  policies/
  NNN-<slug>/
    ticket.md
    contract.yaml
    validation.md
    evidence/
```

Use `wayfinder` for unresolved planning and `execute-frontier` for continuous local execution. No external issue tracker or event watcher is required.

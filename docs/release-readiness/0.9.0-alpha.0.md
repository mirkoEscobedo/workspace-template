## Product boundary

workspace-template owns Adaptive Delivery methodology, read-only embedded skill access, repository inspection, verification, and sealed thin-state migration. Package managers own dependencies and lockfiles. Hosts and repository owners own model, agent, permission, skill, and capability availability.

Direct package identities are platform-specific; the qualified development entry is `workspace-template-win32-x64`. No dispatcher or meta-package is authorized. The executable command remains `workspace-template`.

The canonical product assets are `assets/schemas` and the 13 roots declared by `assets/skills/inventory.json`. Frontier orchestration skills, ticket repair/implementation/review skills, retrofit writers, `write-skill`, presets, generated host configuration, project-agent templates, tooling packs, copied projections/baselines, JavaScript production code, and JavaScript smoke harnesses are deleted from active context.

Required for the first public alpha: read-only skill access, native help/strict arguments/stable exits, update status, package-manager-independent upgrades, project schema v2, platform artifact identity, explicit platform rejection, and Windows cancellation/descendant qualification.

Implemented on this branch: versioned polyglot workspace inspection, conservative conflict/fingerprint evidence, thin-state workspace overrides, dependency-aware module/affected verification, empty-directory adoption, deterministic embedded-skill routing, and the bounded debug schema/provider-discovery boundary.

Still deferred and unqualified: real CDB, GDB, LLDB, Node CDP, Dart DAP, and Flutter DAP protocol adapters; Linux zero-descendant containment and direct-package qualification; macOS containment feasibility; and later platform packages in the accepted order. Experimental Linux code and CI do not change the public Windows x64 platform guard.

Permanently rejected: `create`/scaffolding, projections and copied-skill merges, presets, dependency installation or tooling ownership, generated methodology trees, alignment/restructuring executors, universal script wrappers, and Frontier orchestration. The `create` migration error directs callers to an official initializer followed by sealed adoption.

Authenticode signing with RFC 3161 timestamping is mandatory. Package namespace/ownership, access, maintainers, recovery owners, and signing custodian are human decisions.

# 0.9.0-alpha.0 release candidate notes

Status: source preparation only; unsigned and unpublished.

This release removes the JavaScript product, preset machinery, generated skill projections, self-adoption state, Frontier-era assets, and stale generator documentation. It establishes `assets/skills` as the only skill authority and makes model/agent selection host-owned.

The native CLI adds exact embedded skill discovery, JSON help, strict arguments, stable exits, read-only update status, package-manager-independent sealed migrations, schema-v2 project/artifact identity, explicit platform rejection, and cancellation cleanup qualification.

Publication remains blocked on human package-ownership decisions, clean-runner reproducibility, complete supply-chain evidence, Authenticode signing with RFC 3161 timestamping, signed-byte rescan, isolated-registry qualification, and disposable consumer qualification.

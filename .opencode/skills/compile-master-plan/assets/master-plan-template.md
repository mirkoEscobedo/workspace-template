## Frontier execution policy

Run `execute-frontier` from local repository files. The current conversation remains the coordinator, continues without asking between ordinary tickets, uses one writer by default, parallelizes read-only preflight and independent review, and serially lands passed work. A second writer requires disjoint write sets and conflict keys plus isolated worktrees.

No GitHub issue, webhook, background watcher, or external scheduler is required.

# Agent Documentation

This directory is the durable, versioned memory for agentic work. Chat history is convenience, not authority.

## Canonical files

- `PROJECT_MAP.md` — low-resolution repository orientation.
- `DOMAIN_GLOSSARY.md` — project vocabulary.
- `AUTHORITY_MAP.md` — human, agent, service, and state-transition authority.
- `TEST_TOPOLOGY.md` — test families, fixtures, megafile locks, and commands.
- `PROCESS_POLICY.md` — command ownership and cleanup.
- `FAILURE_CATALOG.md` — recurring failure classes and known repairs.
- `CURRENT_FRONTIER.json` — generated execution frontier.

# Frontier Loop compatibility

Frontier Loop is deprecated in workspace-template 0.7. Announce the compatibility redirect, then use `delivery-loop` to select Direct, Ticketed, or Governed mode.

Do not generate or extend `frontier.json`, Wayfinder decisions, validator scripts, successor tickets, review-attempt trees, or repair campaigns. Preserve existing Frontier files as historical evidence. If unfinished product work remains, summarize current truth and acceptance criteria in one compact Ticketed resumption item.

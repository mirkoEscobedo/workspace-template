# Archive and resume a legacy ticket pack

Leave existing tickets, contracts, decisions, validation files, and evidence byte-unchanged. Add one migration index that records the historical roots, cutoff commit or worktree identity, last selected item, verified product facts, unresolved outcome, and reason execution authority ended.

If work remains, create one compact Ticketed resumption item with current truth, acceptance checks, exclusions, blockers, and selected delivery mode. Do not run the legacy retrofit generator, rewrite statuses, create `frontier.json`, generate Wayfinder artifacts, or copy validator scripts.
